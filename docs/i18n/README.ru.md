# Sonora · Клонирование голоса и синтез речи

[English](../../README.md) · [Языки документации](README.md)

Sonora — самостоятельное SaaS-приложение в каталоге `Voice-clonner-Application/`. Оно не импортирует код существующего YouTube-приложения и не обращается к его API.

## Возможности и текущий статус

- Регистрация, вход, сброс пароля, профиль и личная библиотека голосов.
- Загрузка образцов, сохранение клонированных голосов, синтез речи, прослушивание, скачивание WAV и история.
- Отдельный фоновый worker, SQLite, атомарное резервирование кредитов, возврат при сбое и учёт использования.
- Подписки Stripe, Checkout, клиентский портал и проверка подписей webhook.

Локальное клонирование и синтез проверены на реальном GPU. Перед публичным запуском необходимо настроить и проверить Stripe, SMTP, HTTPS, резервное копирование и мониторинг. Тесты с имитацией платежей не подтверждают реальные оплаты.

## Установка и запуск — Windows / PowerShell

Нужны Python 3.12, uv и NVIDIA GPU с поддержкой CUDA. Модели скачиваются при первом запуске; предусмотрите место на диске для моделей и PyTorch.

```powershell
git clone https://github.com/TalhaFaredi/Voice-clonner-Application.git
cd Voice-clonner-Application
uv sync --extra worker --extra dev
if (-not (Test-Path backend/.env)) { Copy-Item backend/.env.example backend/.env }
```

Откройте три отдельных терминала PowerShell в корне проекта и выполните по одной команде в каждом:

```powershell
./scripts/start.ps1 api
./scripts/start.ps1 worker
./scripts/start.ps1 frontend
```

Откройте **http://localhost:5173** и зарегистрируйте собственную учётную запись. Проверка API: `http://localhost:8010/api/health`. Бесплатная учётная запись получает 5 000 кредитов однократно. Синтез стоит 1 кредит за символ, клонирование — 1 000 кредитов за голос. Используйте одинаковое имя хоста для интерфейса и API.

## GPU и языки

По умолчанию `TTS_DEVICE=cuda:0` использует первый NVIDIA GPU. Работа проверена на NVIDIA RTX A6000 с 48 ГБ VRAM; это не минимальные требования и не гарантия скорости. Проверить GPU можно командой `nvidia-smi`. Для CPU задайте `TTS_DEVICE=cpu` в `backend/.env`; генерация будет медленнее. После изменения настроек перезапустите worker и дождитесь `worker.status: ready` в `/api/studio/options`.

Поддерживаются китайский, английский, японский, корейский, немецкий, французский, русский, португальский, испанский и итальянский языки. `auto` определяет язык текста автоматически. Выбор языка управляет синтезом, но не переводит текст. Интерфейс пока доступен на английском.

## Проверка и развёртывание

Пройдены 13 тестов backend, проверки браузера на компьютере и телефоне, а также реальная цепочка готовый голос → сохранённый клон → синтез речи. Локальный Qwen3-TTS не требует ключа внешнего речевого API. Stripe и SMTP настраиваются отдельно. Не публикуйте `.env`, личные аудиозаписи и базу данных.

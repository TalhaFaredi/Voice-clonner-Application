These guides cover the same application and current setup requirements. The [English README](../../README.md), [deployment guide](../setup.md), [API reference](../api.md), and [verification notes](../verification.md) contain the full operational detail.

Documentation language, interface language, and speech language are different settings. The current interface is English. Translating documentation does not add support for another speech language. The application exposes Chinese, English, Japanese, Korean, German, French, Russian, Portuguese, Spanish and Italian, plus `auto` language detection. It does not automatically translate scripts.
